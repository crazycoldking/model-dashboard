这里为您精选了 GitHub 上 10 个提供高质量提示词（Prompt）范例的仓库。这些仓库按 Star 数量大致从高到低排序，覆盖了 ChatGPT、Claude、Midjourney 等多种工具，包含从入门到进阶、从日常使用到系统级破解的各类提示词。

### 1. f/awesome-chatgpt-prompts
*   **Star 数：** ~115k+
*   **简介：** 全球最著名的提示词仓库之一。它收集了大量用于 ChatGPT 的高质量 Prompt，覆盖了"扮演角色"（Act as...）的各种场景，如 Linux 终端、英语翻译、面试官、旅游向导等。
*   **特点：** 结构清晰，不仅提供了 Prompt，还经常被各大第三方客户端直接集成作为预设库。
*   **适用：** 入门必看，寻找标准化的"角色扮演"类提示词。

### 2. PlexPt/awesome-chatgpt-prompts-zh
*   **Star 数：** ~57k+
*   **简介：** 上述仓库的**中文版**，针对中文语境进行了大量的优化和补充。它是中文互联网上流传最广的 ChatGPT 调教指南。
*   **特点：** 收录了大量适合中文用户的场景，如"周报生成器"、"知乎回答风格"、"小红书文案"等。
*   **适用：** 中文用户首选，直接复制即可使用。

### 3. dair-ai/Prompt-Engineering-Guide
*   **Star 数：** ~46k+
*   **简介：** 这不仅是一个范例库，更是一份**权威的提示词工程指南**。它详细讲解了 Zero-Shot、Few-Shot、CoT（思维链）等高级技巧，并附带了大量学术级和生产级的 Prompt 案例。
*   **特点：** 理论与实践结合，不仅教你"怎么写"，还教你"为什么这么写"。
*   **适用：** 开发者、研究人员、想要深入掌握 AI 原理的高阶用户。

### 4. linexjlin/GPTs
*   **Star 数：** ~33k+
*   **简介：** 这是一个专门收集 **OpenAI GPTs Store 中热门 GPTs 提示词**的仓库。作者通过逆向工程或泄露手段，整理了大量官方和第三方热门 GPTs 的 System Prompt（系统提示词）。
*   **特点：** 可以让你看到那些爆款 AI 应用背后的"源代码"是如何编写的，极具学习价值。
*   **适用：** 想学习如何开发高质量 GPTs 应用的用户。

### 5. x1xhlol/system-prompts-and-models-of-ai-tools
*   **Star 数：** ~15k+
*   **简介：** 专注于收集各大 AI 模型和工具的**系统级提示词（System Prompts）**。不仅包含 ChatGPT，还有 GitHub Copilot、Notion AI 等工具的内部提示词。
*   **特点：** 硬核、深入。能让你了解商业级 AI 产品是如何通过 Prompt 规范 AI 行为的。
*   **适用：** AI 产品经理、Prompt 工程师。

### 6. rockbenben/ChatGPT-Shortcut
*   **Star 数：** ~6.5k+
*   **简介：** 一个可视化的、标签化的提示词库，项目名为"AiShort"。它将 Prompt 按领域（如编程、写作、生活）分类，并提供了标签筛选。
*   **特点：** 更加注重**生产力**和**快捷指令**，不仅有 GitHub 仓库，还有配套的网页版工具，方便查找。
*   **适用：** 需要提高工作效率的日常用户。

### 7. anthropics/prompt-eng-interactive-tutorial
*   **Star 数：** ~2.8k+
*   **简介：** 由 **Claude 官方 (Anthropic)** 提供的交互式提示词工程教程。虽然 Star 数不及前者，但其含金量极高。
*   **特点：** 官方出品，不仅有范例，还有练习题。特别是针对 Claude 模型（擅长长文本和逻辑推理）的 Prompt 技巧非常有针对性。
*   **适用：** Claude 用户，以及想学习官方标准 Prompt 写法的人。

### 8. langgptai/awesome-claude-prompts
*   **Star 数：** ~1.2k+
*   **简介：** 专门针对 **Anthropic Claude** 模型的提示词集合。由于 Claude 和 ChatGPT 的逻辑略有不同（Claude 更喜欢 XML 标签结构），这个仓库提供了很多针对性优化。
*   **特点：** 包含了很多利用 Claude 长上下文能力的 Prompt，如长文档分析、复杂代码生成等。
*   **适用：** 重度 Claude 用户。

### 9. mustvlad/ChatGPT-System-Prompts
*   **Star 数：** ~1.1k+
*   **简介：** 另一个专注于**System Prompts（系统提示词）**的集合，主要关注如何通过系统指令来改变 ChatGPT 的核心行为模式。
*   **特点：** 包含了一些"越狱"或深度定制的技巧，虽然不如前几个大，但内容很垂直。
*   **适用：** 喜欢折腾和深度定制 AI 行为的极客。

### 10. Dalabad/stable-diffusion-prompt-templates
*   **Star 数：** ~700+ (注：绘画类提示词多集中在 Civitai 等网站，GitHub 仓库相对较小)
*   **简介：** 针对 **Stable Diffusion** 的提示词模板库。虽然 GitHub 上绘画类 Prompt 仓库 Star 数普遍不如文本类，但这个仓库提供很好的结构化模板。
*   **特点：** 整理了画质增强词（如 8k, unreal engine 5）、艺术风格词和负向提示词（Negative Prompts）。
*   **适用：** AI 绘画初学者，需要"咒语"模板的用户。
